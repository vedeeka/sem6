---

# 1. BUS TOPOLOGY

| **Parameter**        | **Configuration**                                                                                                                              |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Devices Required     | 4 PCs, 2 Switches (2960)                                                                                                                       |
| Cable Used           | PC → Switch: Copper Straight-Through, Switch → Switch: Copper Cross-Over                                                                       |
| IP Addressing        | PC1: 192.168.1.2, PC2: 192.168.1.3, PC3: 192.168.1.4, PC4: 192.168.1.5                                                                         |
| Subnet Mask          | 255.255.255.0                                                                                                                                  |
| Default Gateway      | 192.168.1.1                                                                                                                                    |

| Expected Output      | Reply from 192.168.1.5                                                                                                                         |

# TELNET CONFIGURATION

### CLI Commands

| **Step**                   | **Command**                            |
| -------------------------- | -------------------------------------- |
| Enter Privileged Mode      | `enable`                               |
| Enter Global Configuration | `configure terminal`                   |
| Enter VLAN Interface       | `interface vlan 1`                     |
| Assign Management IP       | `ip address 192.168.1.1 255.255.255.0` |
| Enable Interface           | `no shutdown`                          |
| Exit                       | `exit`                                 |
| Configure VTY Lines        | `line vty 0 4`                         |
| Set Password               | `password cisco`                       |
| Enable Login               | `login`                                |
| Exit                       | `exit`                                 |
| Enable Password            | `enable password class`                |
| Exit Configuration         | `end`                                  |
| Save Configuration         | `copy running-config startup-config`   |

### Verification

| **Command**          | **Purpose**       |
| -------------------- | ----------------- |
| `telnet 192.168.1.1` | Connect to Switch |
| Password             | cisco             |

# VLAN CONFIGURATION

### Create VLANs

| **Step**           | **Command**          |
| ------------------ | -------------------- |
| Enable             | `enable`             |
| Configuration Mode | `configure terminal` |
| Create VLAN 10     | `vlan 10`            |
| Name VLAN          | `name HR`            |
| Exit               | `exit`               |
| Create VLAN 20     | `vlan 20`            |
| Name VLAN          | `name SALES`         |
| Exit               | `exit`               |

---

### Assign Ports

| **Step**         | **Command**                 |
| ---------------- | --------------------------- |
| Select Port      | `interface fa0/1`           |
| Access Mode      | `switchport mode access`    |
| Assign VLAN      | `switchport access vlan 10` |
| Exit             | `exit`                      |
| Select Next Port | `interface fa0/2`           |
| Access Mode      | `switchport mode access`    |
| Assign VLAN      | `switchport access vlan 20` |
| Exit             | `exit`                      |

---

### Verification

| **Command**           | **Purpose**                           |
| --------------------- | ------------------------------------- |
| `show vlan brief`     | Displays all VLANs and assigned ports |
| `show running-config` | Displays current switch configuration |
